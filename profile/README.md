# Space Concordia Robotics
We are a space robotics team from the University of Concordia based in Montreal, Quebec, Canada.
## What we do
This year we are building a swerve drive rover named Etoile. 
Etoile is engineered to complete the URC missions and ERC tasks.
## Teams
There are currently 5 main teams in this organization:
- General Electrical
- General Mechanical
- General Software
- SCRB-2026-2027
- Software
### General Electrical
All of the electrical members are part of this team. The team owns all of the hardware and firmware repositorty.

### General Mechanical
All of the mechanical members are part of this team.

### General Software
All of the software members are part of this team. The team owns the current repository that is running on the Jetson of the rover.

### SCRB-2026-2027
All of the members who are contributing to either the rovers hardware, firmware or software.

## Projects
After the 2025-2026 season the team has changed their structure.\
Before we were separated into the following teams:
- Electrical
- Mechanical
- Software

This year we are following a matrix organization structure. This new structure introduces many new roles and distributes the workload across different teams. The members are managed by discipline managers:
- Electrical Manager
- Mechanical Manager
- Software Manager

The project is then realized into projects:
- Autonomy Project
- Drone Project
- Arm Project
- Mobility & Frame Project
- Power Project
- Science Project
- TT&C Project
